# Актуальный scope приёмки — 2026-11-01

Решение пользователя: «windows 10 не берём и без webView тоже не тестим».

- Целевая платформа MVP: Windows 11 x64, обычный пользователь.
- WebView2 установлен до запуска; сценарий его отсутствия не входит в приёмку.
- Задачи 7 и 9 сняты (dropped), их проверки не объявляются PASS.
- Задача 10 зависит от системной проверки 8 и готовой native fixture 12; Windows 10 handoff больше не требуется.

Остаются открыты: cross-user DPAPI со второй учётной записью; оставшаяся полная native GUI/stress матрица Windows 11; разрешённые внешние peers/egress и production probe. Эти требования пользователь не исключал. Отсутствие Windows C toolchain по-прежнему ограничивает race instrumentation.

Ранее записанные PASS/FAIL/SKIP и исходный отчёт выполнения сохраняют свой исторический смысл. Их старые blockers Windows 10/missing-WebView2 заменены этим решением, а не новыми результатами тестов. Приёмка MVP ещё не завершена.

Источники: [актуальная спецификация](xray-mini-spec-v0.2.ru.md), [backlog](../_bmad-output/backlog-plan.ru.md), [verification](VERIFICATION.md). Новых запусков приложения при изменении scope не выполнялось.
